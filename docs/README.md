# ResourceVault — Documentation

This folder holds project-level documentation. The **member-facing help centre**
is a polished, searchable section of the app itself at [`/docs`](http://localhost:7843/docs),
sourced from [`apps/web/src/pages/docs/content.ts`](../apps/web/src/pages/docs/content.ts).

## Contents

- [Architecture](./architecture.md) — how the monorepo, API, and client fit together.
- [API reference](./api.md) — every REST endpoint, grouped by module.

## The in-app help centre

The `/docs` help centre is genuine, sector-specific help content with its own
clean, searchable layout. It covers:

- Getting started & creating an account
- Roles explained (Member / Contributor / Admin)
- Finding resources (search + filters)
- Contributing a resource
- The approval & lifecycle workflow
- Admin tasks (members, categories, tags, review queue)
- A comprehensive FAQ
